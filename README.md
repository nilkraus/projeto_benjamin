Sobre o Projeto

O **Projeto Benjamin da Silva Monteiro – Pagina da Web** foi desenvolvido como parte do projeto de extensão II do curso de **Engenharia de Software**, com o objetivo de apoiar ações sociais voltadas para crianças, promovendo educação, inclusão e conscientização.

A proposta consiste na criação de uma **plataforma web informativa e interativa**, que apresenta conteúdos sobre o projeto, incentiva o voluntariado e facilita a comunicação com a comunidade.

## Objetivos

* Apoiar projetos sociais voltados para crianças
* Promover inclusão social e diversidade
* Incentivar o voluntariado e doações
* Disponibilizar informações de forma acessível
* Aplicar conhecimentos práticos de desenvolvimento web

 ## Público-Alvo

* Crianças atendidas pelo projeto social
* Voluntários
* Doadores
* Comunidade em geral
