# Projeto Social Benjamin - Protótipo

Protótipo estático baseado no layout enviado como imagem.

## Estrutura

- `index.html`: marcação principal da página.
- `css/styles.css`: estilos, responsividade e ilustrações em CSS.
- `js/main.js`: interações do menu mobile, galeria, opções de ajuda e formulário.
- `docs/screenshots/`: capturas usadas para verificação visual.

## Como abrir

Abra `index.html` no navegador.
